1. Open the PDF

2. For each page (1 to 3787):
   a. Quick check — does this page contain "dtc" anywhere in its text?
      → NO: skip (fast, avoids running find_tables on every page)
      → YES: continue

   b. Run find_tables() on this page
      → No tables found: skip

   c. For each table found:
      → Check if header row contains "dtc"
      → NO: skip
      → YES: this is an index table

   d. Extract all cells from the table:
      → Collect DTC codes (pattern: P/B/C/U + 4 hex digits)
      → Collect section refs (pattern: ABC-123 style)

   e. If we found at least one DTC code:
      → Record: { pdf_page, code_count, refs[] }

3. Group consecutive PDF pages together
   e.g. pages 150, 151, 152, 153 → one group

4. For each group:
   → Find the section name (e.g. "EVC")
   → Find min and max ref number (e.g. 78 and 81)
   → Count total codes
   → Print: "PDF pages 150-153 → EVC-78 to EVC-81 (45 codes)"
